# QA visualization of the on-board processed data of the CAEN digitizer (DPP-QDC) saved by 00Raw2Np when the raw data    #
# is in CoMPASS binary format (RAW_DATA: COMPASS_BIN). For each selected run/channel it shows:                           #
#   (1) QDC charge spectrum (Energy, integer-aligned binning)                                                            #
#   (2) Trigger rate stability computed from the digitizer timestamps                                                    #
#   (3) Summary of the CoMPASS event flags (pile-up, saturation, etc.)                                                   #
# For the QDC gain fit and the comparison with the ADC waveform analysis use 0TCalQDC.                                   #
